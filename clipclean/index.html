Clipclean

A tiny macOS menu bar utility that strips rich text from the clipboard.

Download for macOS GitHub README Source on GitHub

About

When Plain Text Mode is on, every copy is reduced to its plain-text representation: fonts, colors and other rich flavours are dropped, while Unicode, emoji, tabs and line breaks are preserved. When it is off, the clipboard behaves exactly as macOS normally does.

Highlights

  • Menu bar only — no Dock icon, no main window
  • Liquid Glass panel with a large slide switch
  • Global hot keys: F6 on, F5 off
  • Launch at Login
  • English / 中文 switch inside Settings
  • No network access, no permissions, no history

DevConfig-Gen

Open Source Engine

A lightweight, provider-based configuration engine designed to aggregate multi-source JSON/YAML configurations, run field-level validations, and produce deterministic environment targets with zero runtime overhead.

  • Modular provider pipeline architecture
  • Deep merging with path-specific --set overrides
  • Strict schema validation & path-level diagnostics
  • Unified CLI, interactive wizard, and Web Studio UI
  • Multi-target exports (JSON, YAML, .env)
  • Zero external runtime dependencies

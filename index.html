DevConfig-Gen

Open Source

A local, provider-based engine for generating and validating structured configuration. It merges multiple JSON/YAML inputs, applies overrides, validates every field, and produces deterministic JSON, YAML, or .env artifacts — with no network or system side effects.

  • Provider-based generation pipeline
  • Multi-source deep merge & --set overrides
  • Precise, path-aware validation diagnostics
  • CLI, terminal wizard, and local Web studio
  • Deterministic JSON / YAML / .env output
  • Zero runtime dependencies

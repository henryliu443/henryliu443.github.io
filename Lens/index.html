About

Lens is a native iOS multi-perspective analysis tool: enter a piece of text, pick a Lens, and the AI returns several sections following that Lens's fixed structure. It is not a chat tool — it is structured, multi-perspective review.

The Three Lenses

Decision Review

Calm, structured decision analysis.

Writing Review

A strict but friendly editor.

Communication Review

Anticipates how the other side will read it.

Highlights

  • Three genuinely different reading perspectives
  • Fixed, structured output per lens
  • OpenAI, Anthropic, DeepSeek, or Local (offline)
  • History persisted with SwiftData
  • API keys kept in the Keychain
  • Zero third-party dependencies
